# FormPilot branding

The mark is the exact arrow in DESIGN.md (`M5 12h14M13 6l6 6-6 6`, stroke 2.5), centered at 18px in a 32px rounded tile with radius 10. Light uses indigo `#4F46E5` and white; dark uses `#8B93FF` and `#0D0E13`.

`mark.svg` is the vector master. The local PNG icons at 16, 32, 48, 128 and 256 pixels were rendered from it. `formpilot-logo.png` is a 256px copy. Light/dark wordmarks use the same arrow and FormPilot spelling. The panel renders its mark as inline SVG beside live Manrope text; no generated imagery or network request is needed.
